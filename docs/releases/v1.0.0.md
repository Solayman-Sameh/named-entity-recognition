# v1.0.0 — Named Entity Recognition

First public source release of the English NER training project and local Gradio demo.

- LSTM, BiLSTM, BiLSTM + CRF and fine-tuned cased DistilBERT comparison.
- Selected DistilBERT achieves 90.18% strict test entity F1 on CoNLL-2003.
- Local demo with familiar examples, colored categories, Clear action and conditional results table.
- Raw-text fixes for invisible characters, abbreviations and hyphenated names.
- Complete training notebook, original executed evidence, lightweight reports, UI preview and demo video.
- MIT license for original code.
- Automated Python 3.11/3.12 source, notebook, documentation and model-free regression checks.

## Running the demo

See the repository README. Trained weights are excluded from Git and this source release. The winning fine-tuned DistilBERT model is published on Hugging Face Hub at [`Solayman-Sameh/named-entity-recognition`](https://huggingface.co/Solayman-Sameh/named-entity-recognition). Running `python app.py` on a fresh clone automatically downloads and verifies the model weights, or you can run `python scripts/download_model.py` directly. The retained local app ZIP workflow is also supported.

The updated training notebook has not been retrained end to end. Original benchmark weights/results remain unchanged. CI does not download models, run inference, train models or execute notebook cells.
